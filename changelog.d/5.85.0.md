### v5.85.0 «Тон»
- PWA (uiboshki.ru/app) — теперь то же приложение, что на iPhone: веб-сборка Flutter из `app/` с тем же дизайном, вкладками и настройками «Оформления». Mini App в Telegram остался прежним. Вход прежней PWA переезжает сам — заново входить не надо, установленный значок на экране «Домой» остаётся тем же (тот же манифест, id `/app`).
- Вход через Telegram в PWA на телефоне открывает бота сразу (`tg://`), без белой страницы встроенного браузера; начатый вход с числом переживает перезапуск PWA. Вход через VK/Яндекс в PWA возвращается на `/app`.
- Сборку делает GitHub Actions после мержа изменений в `app/` (`app-web.yml` → `tools/pwa_build.sh` → коммит в `webapp/flutter`); canvaskit — со своего сервера, не с CDN Google. Сборки нет — `/app` отдаёт прежний WebApp. Корень сайта вне Telegram со входом ведёт в `/app`.
