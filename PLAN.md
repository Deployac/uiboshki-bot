## Своё приложение: дорожная карта (07.10, вместо концепта из #120)

Порядок (владелец, 07.10): **1) бот для любой группы института → 2) платформа
без Telegram и PWA → 3) настоящее нативное приложение**, не обёртка. Каждый
этап делается с расчётом на нативное приложение. Магазины (RuStore, Google
Play, App Store) — забота владельца. Mini App и бот остаются как вход для тех,
у кого есть Telegram.

**Сквозные правила — для любой новой функции уже сейчас:**
- данные — структурным JSON, без готового HTML в ответах API (сейчас `html`
  есть в `/api/schedule` и чате: рядом добавляем поля, HTML оставляем Mini App),
  оформление — на клиенте;
- всё «про группу» — из группы человека, а не из `config`;
- рассылки — через слой доставки (этап 2), а не `bot.send_message` напрямую;
- ручки API попадают в схему OpenAPI; ломающее изменение — новая версия.

### Этап 1. Любая группа института (~4–6 активных дней)
Не сложно по смыслу, но широко: «одна группа» зашита примерно в 25 модулях
(`GROUP_NAME` — 11, староста — 23, общая кука СДО — 7, предметы группы — 11).
Владелец прав: группе хватает одного человека со входом в СДО — его календарь
и курсы СДО дают дедлайны и файлы всей группы.
1. **Группа человека** — `users.group_id` (id группы на зеркале МИРЭА,
   справочник уже есть — `schedule_index`). Выбор при первом входе (поиск, как
   на сайте), сменить — в «Ещё». Нынешние пользователи — УИБО-03-24 сами.
2. **Таблица `groups`** — имя, календарь, предметы по выбору, чат группы.
   `GROUP_NAME`, `ICAL_URL`, `OPTIONAL_SUBJECTS`, `GROUP_CHAT_ID` становятся
   значениями по умолчанию для УИБО.
3. **Роли**: владелец — глобально (`/stats`, `/status`, `/channel`, бэкапы);
   **староста группы** — правка общих дедлайнов, файлов, доски ДЗ своей группы.
   Первый подключивший СДО в группе становится её старостой, может передать,
   владелец может назначить. Заодно закрывается вопрос ревью «кто пишет в
   общие данные»: только своя группа, правят старосты группы.
4. **СДО на группу** — синк дедлайнов и файлов по входу «донора»: участник,
   который явно согласился («делиться дедлайнами и файлами СДО с группой»);
   погас вход — берётся следующий. `SDO_SESSION_COOKIE` — запасная для УИБО.
5. **`group_id` в общих данных**: дедлайны (и `deadlines_skipped`), доска ДЗ,
   голосования, «Подслушано», состав группы, снимки расписания. Личное
   (отметки, баллы, напоминания, цели, посещения) — по человеку, как было.
6. **Файлы общие между группами**: один курс СДО у групп потока — один файл
   (`files.source` уже уникален) и связь файл ↔ группа; конспекты и индекс
   поиска тоже общие — бережёт лимит Gemini. Файлы хранятся не в личке
   старосты, а в служебном канале бота (`STORAGE_CHAT_ID`).
7. **Расписание и рассылки по группе**: утро, напоминание перед парой, обзор
   недели — по календарю своей группы (кэш на группу уже есть, 10 минут).
8. **Нагрузка**: рассылки — очередью с паузами (лимит Telegram ~30 сообщений
   в секунду), это зародыш слоя доставки; лимит ИИ (`AI_DAILY_LIMIT`) для всех;
   бесплатного ключа Gemini на институт не хватит — решение владельца
   (платный ключ или жёсткий лимит).
9. **Снаружи**: `/start` спрашивает группу, сайт — «для любой группы МИРЭА»,
   `/stats` — по группам, пост в канал.
Риски: входы СДО многих людей (шифрование уже есть) — нужно явное согласие и
«удалить мои данные»; персональные данные хранить по минимуму.
PR по шагам: (а) `groups`, `users.group_id`, выбор группы — пока одна группа;
(б) `group_id` в общих данных и роли; (в) СДО-донор, файлы между группами;
(г) рассылки по группам и очередь; (д) сайт, описание, пост.

### Этап 2. Платформа без Telegram и PWA (~3–4 активных дня)
Сервер, который одинаково обслуживает Mini App, PWA и нативное приложение;
PWA — его первый клиент.
1. **Аккаунт ≠ Telegram**: в России Telegram открывается через «КВН», значит
   приложение не должно требовать Telegram. Внутренний id: у нынешних — их id
   в Telegram (ничего не переносить), у новых без Telegram — из своего
   диапазона (от 10^15). Таблица `identities` (человек, способ, внешний id).
   Вход: через бота (одноразовая ссылка → «Да, это я»), код на почту, позже
   VK ID / Яндекс ID; второй способ привязывается в «Ещё → Аккаунт».
2. **Сессии**: `sessions` (хэш токена, человек, устройство, последний заход),
   короткий токен доступа + долгий для обновления (так нужно приложению);
   `get_current_user` принимает initData или `Authorization: Bearer`;
   «Ещё → Устройства», «выйти везде».
3. **API v1 как контракт**: `/api/v1/…` (старые пути — синонимы для Mini App),
   структурные ответы, снимок схемы OpenAPI в тестах (ломающее изменение —
   красный CI), `/api/meta` с минимальной версией клиента («обнови
   приложение»), ETag и «что изменилось с …» для офлайна.
4. **Слой доставки**: `deliver(человек, вид, текст, ссылка)` → очередь →
   Telegram, Web Push, позже FCM, APNs, RuStore Push; все рассылки — через
   него; в уведомлениях выбор «куда присылать».
5. **Ссылки на экраны** — единые пути (`/d/123`, `/s/<курс>`) из Telegram,
   PWA, пуша, позже universal links / app links.
6. **Дизайн-токены**: цвета, шрифты, радиусы, отступы из `app.css` →
   `design/tokens.json`; из него собираются CSS и тема приложения — один
   дизайн везде.
7. **PWA**: manifest, иконки, service worker (оболочка + последнее расписание
   и дедлайны без сети), экран входа, подсказка «На экран Домой» для iPhone,
   Web Push (на iPhone — iOS 16.4+ и только с экрана «Домой»); вызовы Telegram —
   через `js/platform.js`. Корень `uiboshki.ru`: со входом — приложение, без —
   сайт.

### Этап 3. Нативное приложение (~2–4 недели активной работы)
Владелец: настоящее хорошее приложение, а не Mini App без Telegram. Поэтому
обёртки (Capacitor, TWA) — **нет**; свой интерфейс.
- **Flutter**: один код на Android и iOS, свой дизайн рисуется точно (у нас и
  так своя дизайн-система и иконки), плавные анимации, офлайн-база (SQLite).
  Два родных приложения (SwiftUI + Compose) — вдвое больше работы, не берём.
- **Чем оно лучше Mini App**: всё работает без сети (расписание, дедлайны,
  баллы, скачанные лекции); виджеты на экране «Домой» (следующая пара,
  ближайший дедлайн); на iPhone — Live Activity и Dynamic Island («идёт пара,
  до конца 23 мин, дальше — А-17»); пуши с кнопками («Сдано», «Напомнить
  вечером»); сдача работы из «Файлов» или камеры (скан листа в PDF);
  календарь телефона; жесты, тактильный отклик, системная тема.
