Ночь, код и светильник · 2/2 #заметки · продолжение 🔐 Секреты в базе — только шифрованными Вход в СДО у бота хранится вот так: 
from cryptography.fernet \
    import Fernet

f = Fernet(KEY)  # ключ — не в базе!
token = f.encrypt(b"секрет")
f.decrypt(token)  # → b"секрет"
Даже если базу кто-то утащит, без ключа там просто мусор из букв. Ключ лежит отдельно — в настройках сервера. Долго думал, как потом менять ключ, не теряя уже подключённых. Оказалось, всё придумано до меня: MultiFernet берёт список ключей — шифрует новым, а расшифровывает любым. Старые записи потихоньку перешифровываются сами. Где ещё: токены от чужих сервисов, пароли, любые данные, которые не должны лежать в базе открытым текстом. ⏳ Ссылки, которые сами протухают Кнопка «Скачать» в приложении даёт ссылку на файл, которая живёт 10 минут: 
def sign(file_id, exp):
    msg = f"dl:{file_id}:{exp}"
    return hmac.new(SECRET,
        msg.encode(), sha256
    ).hexdigest()[:32]

exp = int(time.time()) + 600
sig = sign(file_id, exp)
url = f"/dl/{file_id}" \
      f"?exp={exp}&sig={sig}"
exp — до какого момента ссылка действует, sig — подпись секретным ключом. Сервер, получив ссылку, проверяет две вещи: срок не вышел и подпись сходится. Поменяешь в ссылке номер файла или срок — подпись не совпадёт, а подделать её без ключа нельзя. Никакой таблицы «выданных ссылок» хранить не надо. Где ещё: «ссылка действует 24 часа», приглашения, сброс пароля, доступ к файлу без логина. 🛟 Сайт лёг — показываем последнюю копию

Сайт МИРЭА иногда тормозит или лежит, а расписание в боте всё равно открывается — из последней удачной копии. Четыре строчки, а пользы больше, чем от половины фич. Где ещё: курсы валют, погода, любой внешний сервис, на который нельзя положиться. 🔴 А вот тут не вышло Хотел показывать посещаемость по датам из Пульса МИРЭА — где ты отмечен, где нет. Написал проверку, пускает ли Пульс сервер бота: 
r = await client.get(PULSE_URL)
body = r.text.lower()
if "ddos-guard" in body:
    return "не пускает"
Пульс прикрыт защитой DDoS-Guard, а она режет адреса дата-центров. Сервер бота — как раз в дата-центре. С моего телефона открывается, с сервера — нет.
Ночь, светильник, кола, смотрю на красный кружок «🔴 DDoS-Guard не пускает адрес сервера» и думаю: ну блять.
