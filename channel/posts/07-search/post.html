Расписание всего МИРЭА 26 сентября 2026 · #история · протокол вскрытия Помните, с чего всё началось? С поиска расписания, который отваливался с включённым «КВН». 26 сентября бот эту боль закрыл. Разберём, как это вскрывалось — по шагам, как операцию. 🩺 Пациент Ссылка на календарь нашей группы — та самая, которой бот пользуется с первого коммита в апреле: english.mirea.ru/schedule/api/ical/1/4928. Внутри — обычный файл календаря. Вот его настоящее начало: 
BEGIN:VCALENDAR
VERSION:2.0
X-WR-CALNAME:УИБО-03-24
…
BEGIN:VEVENT
DTSTART:20260914T090000
SUMMARY:СР Производственная
  практика
LOCATION:кафедра (В-78)
RRULE:FREQ=WEEKLY;INTERVAL=2
END:VEVENT
Каждая пара — блок VEVENT: когда (DTSTART), что (SUMMARY), где (LOCATION) и как повторяется (RRULE — раз в две недели). А в третьей строке — X-WR-CALNAME, название календаря. Запомните его — пригодится. 🔪 Разрез Я посмотрел на хвост ссылки: /1/4928. 4928 — явно номер нашей группы. А единица? Выяснил опытным путём — просто менял цифры: 
/ical/1/4928 → УИБО-03-24
/ical/2/…    → преподаватель
/ical/3/…    → аудитория
Через одну дверь можно достать расписание кого угодно. Нужно только знать номер. ⚠️ Осложнение А номер никто не знает. Официальный поиск по имени живёт на основном сервере МИРЭА, а тот из-за рубежа не отвечает — сервер бота как раз за рубежом. На живом тесте /teacher Морозов висел секунд сорок и отвечал «не нашёл». А у зеркала поиска нет вовсе: /search → 404. 🧠 Решение Нет поиска — составим справочник сами: перебрать номера 1, 2, 3… и у каждого прочитать только название. Весь файл не нужен — хватит первого килобайта: 
async def fetch_title(client, t, i):
  url = f"{MIRROR}/ical/{t}/{i}"
  hdr = {"Range": "bytes=0-1023"}
  async with client.stream(
      "GET", url, headers=hdr) as r:
    if r.status_code == 404:
      return None  # номера нет
    head = b""
    async for c in r.aiter_bytes():
      head += c
      if len(head) >= 1024:
        break  # обложку прочли
  m = NAME_RE.search(head)
  return m and m.group(1).decode()
Range — просьба к серверу «пришли только байты с 0 по 1023». 404 — такого номера нет. Набрали килобайт — обрываем загрузку и достаём из него X-WR-CALNAME. Как прочитать обложку книги, не открывая её. 🧵 Швы Перебор — вежливый, по 4 запроса одновременно. Упрощённо: 
while misses < 300:
  ids = range(next_id, next_id + 20)
  for i, title in await scan(ids):
    if title:
      save(t, i, title); misses = 0
    else:
      misses += 1
  next_id = ids[-1] + 1
300 пустых номеров подряд — значит, дальше никого. Бот перезапустился — продолжит с того же номера. Раз в месяц обход повторяется: новые группы появляются в конце. 📋 Выписка Дальше поиск — обычный запрос к своей базе: 
SELECT type, id, title
FROM schedule_targets
WHERE title_lc LIKE '%морозов%'
ORDER BY title_lc LIKE 'морозов%'
  DESC, length(title)
Сначала те, что начинаются с запроса: «Морозов» раньше «Шморозовой». А выпустившиеся группы не показываются: на первой проверке по «БАСО» весь верх заняли группы 2012–2017 годов. Многие скажут — костыль. Но это даже устойчивее, чем было: у бота своя база — справочник и копия расписания группы. Сайт МИРЭА лежит — бот показывает сохранённое и пишет, от какого числа данные.
Самый большой восторг за весь проект. Решение, которое я не побоюсь назвать гениальным.
