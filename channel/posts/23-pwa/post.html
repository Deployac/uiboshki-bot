Бот без Telegram #обновление · приложение В прошлом посте были строчки кода и подсказка под спойлером: бот перестаёт быть только ботом. Рассказываю. Я хотел, чтобы расписание и сроки открывались всегда — даже когда Telegram грузится через раз или без КВН не открывается вовсе. И чтобы этим можно было пользоваться, даже если Telegram у человека вообще нет. Теперь можно: uiboshki.ru/app Как поставить • iPhone — открыть ссылку в Safari → «Поделиться» → «На экран „Домой“». • Android — в Chrome → «Установить приложение». • Компьютер — тот же адрес в Chrome, Edge или Яндекс Браузере, значок «Установить» в адресной строке. Появляется значок с капибарой, открывается на весь экран, без адресной строки — как обычное приложение. В самом боте подсказка тоже есть: «Ещё → Установить». Вход — без паролей Нажимаешь «Войти через Telegram», бот спрашивает: «Войти на Chrome · Android?» — «Да, это я», и всё. Можно и через VK ID — тогда Telegram не нужен совсем. Пароль я не храню, потому что его нет: устройству выдаётся свой ключ, а в базе лежит только его отпечаток. Список устройств и «выйти везде» — в «Безопасности». Без сети Расписание и сроки открываются и в метро — показывается то, что приходило в последний раз. Сначала приложение ждёт сервер пять секунд, потом берёт сохранённое: 
try {
  const resp = await Promise.race(
    [fetch(req), timeout(ms)]);
  if (resp.ok) cache.put(req, resp.clone());
  return resp;
} catch (e) {
  const hit = await cache.match(req);
  if (hit) return hit;
  throw e;
}
Уведомления Пары, сроки, новые задания и баллы приходят пушем — как от любого приложения. На iPhone пуши работают, когда приложение добавлено на экран «Домой». Включаются в «Ещё → Уведомления».
Ещё по мелочи • Тема — как у телефона: светлая днём, тёмная ночью, если так настроено. • Данные везде одни: отметил срок в Telegram — он отмечен и в браузере. • Первая версия на iPhone залезала шапкой под часы — поймали по скрину с iPhone 16 Pro и починили на следующий день.
