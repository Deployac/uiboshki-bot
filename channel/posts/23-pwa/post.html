Бот без Telegram #обновление · приложение В прошлом посте я оставил семь строчек кода и подсказку под спойлером: бот перестаёт быть только ботом. Пора объяснить. Я хотел, чтобы расписание и сроки открывались всегда — даже когда Telegram грузится через раз или без КВН не открывается вовсе. И чтобы ботом мог пользоваться человек, у которого Telegram нет совсем. Теперь так и есть:
uiboshki.ru/app — расписание, сроки, файлы, СДО и ИИ, только в браузере.
Как поставить • iPhone — открыть ссылку в Safari, «Поделиться» → «На экран „Домой“». • Android — в Chrome: «Установить приложение». • Компьютер — Chrome, Edge или Яндекс Браузер, значок «Установить» в адресной строке. Появится значок с капибарой. Открывается на весь экран, без адресной строки — как обычное приложение. Забыл, как ставить, — в боте есть подсказка: «Ещё → Установить». Это вторая строчка из тизера: 
"start_url": "/app",
"display": "standalone"
standalone говорит телефону: открывай без адресной строки, как приложение. Вход — без паролей Нажимаешь «Войти через Telegram», бот спрашивает: «Войти на Chrome · Android?» Отвечаешь «Да, это я» и нажимаешь в боте число, которое видишь на экране, — как при входе в Google. Чужую ссылку так не подсунуть: без твоего экрана число не угадать. Telegram нет — можно войти через VK ID. Пароль я не храню, потому что его нет: устройство получает свой ключ, а в базе лежит только его отпечаток — войти по нему нельзя. Все устройства и «Выйти везде» — в «Ещё → Безопасность». Без сети В метро расписание и сроки всё равно откроются — покажется то, что приходило в последний раз. Приложение ждёт сервер пять секунд, а не дождалось — берёт сохранённое: 
try {
  const resp = await Promise.race(
    [fetch(req), timeout(ms)]);
  if (resp.ok) cache.put(req, resp.clone());
  return resp;
} catch (e) {
  const hit = await cache.match(req);
  if (hit) return hit;
  throw e;
}
Каждый удачный ответ кладётся про запас (cache.put), а сеть пропала — достаётся оттуда (cache.match). Уведомления Пары, сроки, новые задания и баллы приходят пушем, как от любого приложения, — даже когда Telegram закрыт. Включаются в «Ещё → Уведомления». На iPhone пуши работают, только когда приложение добавлено на экран «Домой», — так решила Apple. Третья строчка из тизера — отсюда. Каждый пуш шифруется ключом только для твоего телефона, и сервер Google или Apple, через который он идёт, прочитать его не может: 
ikm = _hkdf(auth_secret, shared,
    b"WebPush: info\x00" + ua_pub + as_pub, 32)
Ещё по мелочи • Тема — как у телефона: светлая днём, тёмная ночью, если так настроено. • Данные везде одни: отметил срок в Telegram — он отмечен и в браузере. • Первая версия на iPhone залезала шапкой под часы. Я увидел это на скрине с iPhone 16 Pro и починил на следующий день.
Остались ru.uiboshki.app и позы капибары. Это следующий шаг — своё приложение для Android и iPhone. Не сайт в рамке, а настоящее. У него уже есть имя: Капибара.
